# Kebijakan Keamanan & Pengelolaan Kredensial

1. **Private Key Privacy:** File `identity.pem` bersifat rahasia. Jangan pernah mengunggahnya ke repositori ini atau membagikannya ke media sosial.
2. **Passphrase Security:** Passphrase DID digunakan untuk enkripsi lokal. Jangan samakan dengan password akun atau seed phrase wallet kripto Anda.
3. **Account Safety:** Amankan akun GitHub Anda dengan mengaktifkan Two-Factor Authentication (2FA).
